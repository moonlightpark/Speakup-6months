# 🎤 SpeakUp 6M — 6개월 영어 듣기·말하기 완성

**6개월 뒤, 영어로 듣고 말할 수 있게.** SpeakUp 6M은 소리로 알려 주고, 내 목소리를 듣고, 잘 따라 했는지 바로 알려 주는 **음성 중심 영어 학습 데스크톱 앱**입니다. macOS와 Windows에서 동작하며 웹 브라우저가 아닌 네이티브 앱(Rust)입니다.

> 학습 비중은 **말하기 40 · 듣기 30 · 읽기 15 · 쓰기 15**. 말은 들은 만큼 나오기 때문에 말하기와 듣기가 전체의 70%입니다.

> 🎯 **6개월 목표: B1** — 일상·업무 주제로 10분 동안 막히지 않고 대화하기. 말하기가 눈에 띄게 늘려면 보통 200~300시간이 필요해서, **하루 60분(앱) + 유튜브·팟캐스트 듣기 30분**을 권합니다. 앱의 하루 목표 기본값도 60분입니다(설정에서 바꿀 수 있어요).

## 🚀 처음 시작하기 (5분)

1. **이름**과 **Claude API 키**를 입력합니다. 한 번 입력하면 다시 묻지 않아요.
2. **음성 인식 모델**(142MB)을 받습니다 — 내 발음을 알아듣는 데 씁니다.
3. **자연스러운 AI 음성**(약 330MB)을 받습니다 — 원어민처럼 매끄러운 목소리로 읽어 줍니다.
4. **마이크·스피커 점검**: 3초 말하고 다시 들어 보세요.
5. **레벨 테스트**를 보면 내 수준에 맞는 6개월(182일) 과정이 시작됩니다.

모델은 **한 번만** 받으면 되고, 이후에는 인터넷 없이도 음성 인식과 음성 재생이 됩니다.

## ✨ 주요 기능

### 🎤 따라 말하기 채점
마이크 버튼을 누르고 말하면, 오프라인 음성 인식(Whisper)이 알아듣고 **단어마다 맞았는지** 색으로 보여 줍니다. 통과할 때까지 여러 번 소리 내어 읽게 하고, 말하기 속도(WPM)도 알려 줍니다.

> ℹ 점수는 음성 인식이 내 말을 얼마나 잘 알아들었는지, 즉 **알아듣기 쉬운 정도(명료도)** 입니다. 원어민처럼 들리는지를 재는 점수는 아니에요.

### 🔊 자연스러운 원어민 음성
신경망 음성 합성 **Kokoro**로 사람처럼 매끄럽게 읽어 줍니다. 미국·영국 남녀 11가지 목소리 중에서 고를 수 있고, **🐢 천천히 / 🐇 빠르게**도 자연스럽습니다. 한 번 들은 문장은 바로 다시 재생됩니다.

### 📖 직독직해
영어 어순 그대로 끊어 읽고, 각 조각 아래에 한글 뜻을 보여 줍니다.

직독직해는 초반에 영어 어순을 익히는 데 효과적이지만, 계속 쓰면 머릿속에서 번역하는 습관이 굳어 말이 느려집니다. 그래서 **한국어 도움이 기간에 따라 줄어듭니다.**

| 기간 | 직독직해·한국어 |
|---|---|
| 1~2개월 | 직독직해와 색상을 항상 켜 둡니다 |
| 3~4개월 | 기본은 꺼 두고, 📖 직독직해 버튼으로 필요할 때만 켭니다 (한글 지문 색상도 한 번 자동으로 꺼져요) |
| 5~6개월 | 영어만 봅니다. 한국어 뜻은 말해 본 뒤나 "한국어 뜻 보기"를 눌렀을 때만 |

```
I  /  am  /  a  /  boy
나 /  이다 /  한 / 소년
```

조각마다 **문장 성분 색상**이 붙습니다. 중요한 주어·동사는 진하게, 덜 중요한 말일수록 회색에 가깝게 표시합니다.

| 색 | 성분 | 예 |
|---|---|---|
| 🟥 빨강 | 주어 | I / 나 |
| 🟦 파랑 | 동사 | am / 이다 |
| 🟪 보라 | 목적어 | coffee / 커피를 |
| 🟩 초록 | 보어 | boy / 소년 |
| 🩷 분홍 | 대명사 | my / 내 |
| 🟧 주황 | 관사·수 | a / 한 |
| ⬜ 회색 계열 | 수식어 · 전치사·접속사 | very, in / 그리고 |

문장 해석, 작문 문제, 대화 번역 같은 **한글 지문도 같은 색으로** 표시합니다. 지문은 문장마다 줄을 바꾸고 문장 사이에 여백을 두어 읽기 편하게 했습니다. 눈이 피로하면 **설정 → 학습 → "한글 지문에 문장 성분 색상 표시"** 를 끄세요. 직독직해 색상은 📖 직독직해 버튼으로 따로 켜고 끕니다.

### 📘 리딩 라이브러리 — 동화책부터 소설까지
내 레벨에 맞는 책을 추천합니다.
- **동화**: 사자와 생쥐, 양치기 소년, 토끼와 거북이, 개미와 베짱이, 빨간 암탉, 골디락스, 미운 오리 새끼 (학습용으로 다시 쓴 이야기, 내장)
- **어린이 고전**: 피터 래빗, 오즈의 마법사, 이상한 나라의 앨리스
- **소설**: 비밀의 화원, 톰 소여의 모험, 크리스마스 캐럴, 셜록 홈즈, 위대한 개츠비, 오만과 편견

원문은 저작권이 끝난 퍼블릭 도메인 작품(Project Gutenberg)이라 무료로 한 번만 받아 둡니다. 문장을 누르면 **듣기 · 직독직해 · 소리 내어 읽기(채점) · 단어 뜻 · 복습 저장**을 할 수 있고, 어려우면 **✨ 쉬운 영어로 다시 쓰기**로 내 수준에 맞게 바꿔 읽을 수 있어요. 읽던 페이지는 자동으로 기억합니다.

### 📖 내장 영어 사전 (6,000단어)
리딩에서 문장 아래 단어를 누르면 **앱에 들어 있는 6,000단어 사전**(`assets/words6000.json`: 품사·한국어 뜻·예문·예문 해석)에서 바로 뜻을 보여 줍니다. 인터넷이나 Claude API가 필요 없어요. went → go, cities → city, stopped → stop처럼 바뀐 형태도 기본형으로 찾아 줍니다. 사전에 없는 단어(이름, 6,000단어 밖의 단어)만 원하면 **🔎 문맥 뜻 묻기**로 Claude에게 물어볼 수 있어요.

### ✏ 쓰기
- **🎧 받아쓰기**: 배운 문장을 듣고 그대로 쓰기 (단어별 채점)
- **🔁 한→영 작문**: 한국어를 영어로. 모범 답안과 달라도 뜻이 같으면 AI가 맞다고 인정해요
- **📝 영어 일기**: 짧은 글을 쓰면 AI가 교정하고 원어민 버전을 보여 줍니다. 교정된 글은 **소리 내어 읽어서** 말하기 연습으로 이어져요

### 🌐 자동 번역기 — 한국어로 말하면 영어 3단계로
하고 싶은 말을 **한국어로 마이크에 말하거나** 입력하면, 같은 뜻을 **쉽게 · 중간 · 고급** 세 가지 영어 표현으로 바꿔 보여 주고 원어민 음성으로 읽어 줍니다. 표현마다 핵심 팁이 붙고, **🎤 따라 말하기**로 바로 연습하거나 **⭐ 저장**해서 복습에 넣을 수 있어요.

```
🎤 "오늘 회의 좀 미룰 수 있을까요?"
 쉽게  Can we move the meeting?
 중간  Could we push the meeting back a bit?
 고급  Would it be possible to reschedule today's meeting?
```

한국어 음성 인식 모델(466MB 또는 142MB)은 처음 한 번만 받습니다.

### 🔗 단어보다 덩어리 표현
- **덩어리 표현**: "I was wondering if", "It depends on", "I'm thinking about"처럼 원어민이 늘 쓰는 표현을 통째로 외우고 말합니다. 단어 하나를 외우는 것보다 회화에 훨씬 빨리 효과가 나요. 매일 4개, 새 단어보다 먼저 연습합니다.
- **고빈도 어휘 — 내장 6,000단어 데이터베이스**: "필수 영어단어 Top 5,000 (1~6000)" 순위표의 6,000단어에 한국어 뜻·예문·예문 해석을 붙여 앱에 넣었습니다. **새 단어** 메뉴는 Claude를 기다리지 않고 이 데이터에서 레벨에 맞는 단어를 바로 고릅니다(초급·A2는 1위부터, B1은 500위대, B1+는 1,500위대, B2는 2,500위대부터). 이미 배운 단어는 빼고, 그날 고른 단어는 앱을 다시 켜도 그대로입니다.
- **외운 정도가 색으로 보여요**: 새 단어 리스트는 25개씩 쪽으로 나뉘고, 단어마다 지금까지 통과한 횟수가 색과 "3/10회"로 표시됩니다. 🟥 미완료(빨강) → 🟧 반복 중(진한 주황에서 진한 연두로 점점) → 🟩 기억 완료(연두, 10회 이상). 기록은 학습 기록 폴더의 `word_stats.json`에 따로 저장됩니다. 리스트에서 **단어를 클릭하면 그 단어만 바로 연습**할 수 있어요.
- **통과한 단어는 한 번만**: 3번 통과해 단어장에 들어간 단어는 앱을 다시 켜도 처음부터 3번 반복하지 않고 한 번만 확인하고 넘어갑니다.

### 💬 원어민 표현과 유행어
교과서 문법 대신 원어민이 실제로 쓰는 문장으로 배웁니다. 표현·유행어는 재미 요소라 **하루 1개(새로 배우는 양의 약 5%)** 만 넣고, **예전부터 쓰던 표현**(my bad, rain check, as if! …)과 **요즘 유행어**(no cap, low-key, it's giving… …)를 하루씩 번갈아 배워요.

### 🔁 복습과 숙제
배운 단어·문장은 잊을 때쯤 다시 나옵니다(SM-2 간격 반복). 복습은 **덩어리 표현과 문장이 중심**입니다. 이것들이 먼저 나오고, 단어는 한 번 복습의 40%까지만 넣습니다(복습할 표현·문장이 부족하면 단어로 채워요). 자꾸 틀리는 문장·단어는 **약점**으로 표시되어 더 여러 번 반복하고, 다음 날 **숙제**로 다시 확인합니다.

### 🔬 피드백 센터
자주 틀리는 발음 단어(3번 연속 맞히면 해결)와 AI가 교정해 준 문장을 모아 다시 연습합니다.

### 👂 듣고 대답하기
리스닝 랩의 두 번째 탭. 원어민이 실제로 건넬 법한 질문을 **글자 없이 소리로만** 듣고 영어로 바로 대답합니다. Claude가 질문을 제대로 이해했는지, 대답이 어울리는지 판단하고 더 자연스러운 대답을 알려 줘요. 질문 글과 해석은 대답한 뒤에 보입니다. 이해한 대답은 오늘의 듣기 목표에 포함됩니다.

### ⏱ 4/3/2 말하기
스피드 트레이닝의 세 번째 탭. 같은 주제를 **4분 → 3분 → 2분** 동안 반복해서 말합니다. 같은 내용을 더 짧은 시간에 말하면서 유창해지는 훈련으로, 라운드마다 단어 수와 말하기 속도(WPM)를 비교해 보여 줍니다.

### 🧠 한국어 보고 영어로 말하기
기억을 꺼내 말하는 연습이 효과가 가장 큽니다. 복습과 순발력 말하기는 물론, 문장 읽기와 덩어리 표현을 마친 뒤에도 **한국어만 보고 영어로 한 번 더** 말합니다.

### 📼 주간 녹음 비교 · 🎓 원어민 수업 · 📝 모의고사
**레벨 · 평가** 화면에서 관리하고, 할 일이 있으면 홈 화면 **이번 주 할 일**에 나옵니다.
- **주간 녹음**: 매주 같은 질문("Tell me about yourself and what you did this week.")에 1분 동안 대답해 녹음합니다. 처음 녹음과 최근 녹음을 나란히 들어 보고 1분에 말한 단어 수를 비교해요.
- **원어민 화상 수업**: AI 롤플레이만으로는 예상 못 한 반응에 대처하는 경험이 부족합니다. 3개월 차(Day 61)부터 주 1~2회, 30분씩 원어민과 화상 수업(예: italki)을 권하고, 수업한 날을 기록합니다.
- **외부 모의고사**: 2주마다 OPIc이나 TOEIC Speaking 모의고사로 실력을 확인하고 결과(등급·점수)를 기록합니다.

### 📈 레벨과 기록
레벨(초급~능숙, CEFR A1~C1)은 파일로 기록되고 4주마다 레벨 평가를 봅니다. **학습 기록**에서 날짜별로 무엇을 몇 분 했는지, 읽은 책, 쓴 글, 점수를 확인할 수 있어요.
홈의 **📊 진척율** 카드: **새 단어**는 배운 단어 수 / 6,000단어, **문장 소리내어 읽기**는 배운 숙어 문장 수 / 1,300문장으로(하나를 통과할 때마다 올라가고, 10회 이상 연습한 '기억 완료' 수도 표시), 스피드 리딩·말하기 · 자기 표현 말하기 · 비즈니스 회화 · 리딩 · 쓰기는 6개월(182일) 중 며칠 마쳤는지 보여 줍니다. 문장 읽기 리스트도 새 단어처럼 연습 정도에 따라 색이 바뀌고, 문장을 클릭하면 그 문장만 바로 연습할 수 있어요.

## ❓ 자주 묻는 질문

**Claude API 키가 꼭 필요한가요?**
레슨 생성, 말하기·쓰기 피드백, AI 회화, 쉬운 영어로 다시 쓰기에 사용합니다. 키가 없어도 내장 레슨·동화·받아쓰기 등은 쓸 수 있어요. 키는 [Anthropic Console](https://console.anthropic.com/)에서 만들고, 내 컴퓨터에만 저장됩니다.

**마이크가 안 돼요.**
설정 → **오디오 장치 · 마이크 점검**에서 "마이크 테스트"를 눌러 보세요. 원인을 알려 줍니다.
- macOS: 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 SpeakUp 6M을 허용하세요.
- 맥북 **덮개를 닫고** 외부 모니터를 쓰면 내장 마이크가 꺼집니다. 덮개를 열거나 헤드셋 마이크를 연결하세요.

**소리가 안 나요 (macOS).**
앱 위쪽에 "시스템 오디오가 응답하지 않습니다"가 보이면 macOS 오디오가 멈춘 상태입니다. 터미널에서 `sudo killall coreaudiod`를 실행하세요.

**화면을 밝게 바꿀 수 있나요?**
네. **설정 > 🎨 테마**에서 🌙 다크(기본) / ☀ 라이트를 고르면 바로 바뀌고, 다음에 켤 때도 그대로입니다.

**스피드 리딩 지문은 어디서 오나요?**
학습 기록 폴더의 `passages` 폴더에 있는 책(그레이디드 리더)에서 내 레벨에 맞는 책을 골라, 읽던 쪽부터 한 쪽씩 텍스트로 보여 줍니다(초급 0단계 → 1단계 → 2단계 → 중급 이상 3단계). 각 책은 `{"stage": 0, "title": "...", "pages": ["1쪽 텍스트", ...]}` 형식의 JSON 파일입니다. 내가 가진 PDF에서 뽑은 텍스트라 앱에는 포함되지 않으며, 폴더가 비어 있으면 Claude가 만든 지문으로 연습합니다.

**문제가 생기면 무엇을 보내면 되나요? (개발 중 디버그 로그)**
학습 기록 폴더의 `logs/speakup.log`에 앱 시작, 화면 이동, 녹음·음성 인식, Claude 요청, 오류, 1분마다의 메모리 사용량이 남습니다. 5MB가 넘으면 `speakup.old.log`로 넘어가 계속 커지지 않습니다. API 키는 기록하지 않습니다.

**메모리를 얼마나 쓰나요?**
원어민 음성 엔진이 가장 큽니다(약 1.3GB). 그래서 앱을 켤 때 바로 올리지 않고 처음 읽어 줄 때 올리며, 5분 동안 쓰지 않으면 내려놓습니다. 음성 인식 모델도 3분 동안 쓰지 않으면 내려놓습니다.

**내 학습 기록은 어디에 저장되나요?**

| OS | 위치 |
|---|---|
| macOS | `~/Library/Application Support/com.SpeakUp.SpeakUp6M/` |
| Windows | `%APPDATA%\SpeakUp\SpeakUp6M\data\` |

**태블릿에서도 쓸 수 있나요?**
지금은 데스크톱 전용입니다. 학습 엔진은 Android/iOS로 옮길 수 있게 만들어져 있어, 나중에 iPad·안드로이드 패드처럼 큰 화면에서는 데스크톱과 같은 화면 구성으로 제공할 계획입니다.

## 🛠 직접 빌드하기

Rust 1.86 이상과 CMake가 필요합니다.

빌드는 메모리를 아끼도록 동시 작업 수를 4개로 제한해 두었습니다(`.cargo/config.toml`). 메모리가 넉넉하면 `cargo build -j 8`처럼 늘릴 수 있습니다.

```bash
cargo run --release              # 실행
cargo test                       # 테스트
./scripts/bundle_macos.sh        # macOS .app 만들기
```
