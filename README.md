# 🎤 SpeakUp 6M JP — 6개월 일본어 듣기·말하기 완성

**6개월 뒤, 일본어로 듣고 말할 수 있게.** SpeakUp 6M JP는 소리로 알려 주고, 내 목소리를 듣고, 잘 따라 했는지 바로 알려 주는 **한국인을 위한 음성 중심 일본어 학습 데스크톱 앱**입니다. macOS와 Windows에서 동작하며 웹 브라우저가 아닌 네이티브 앱(Rust)입니다.

> 이 앱은 영어판 [SpeakUp 6M](https://github.com/moonlightpark/Speakup-6months)을 일본어 학습용으로 전면 수정한 버전입니다(`japanese` 브랜치). 학습 기록 폴더도 영어판과 따로 씁니다.

> 학습 비중은 **말하기 40 · 듣기 30 · 읽기 15 · 쓰기 15**. 말은 들은 만큼 나오기 때문에 말하기와 듣기가 전체의 70%입니다.

> 🎯 **6개월 목표: JLPT N3 수준의 회화** — 일상·업무 주제로 10분 동안 막히지 않고 대화하기. 한국어와 일본어는 어순이 같고 한자어가 많아서 영어보다 빨리 늡니다. **하루 60분(앱) + 일본어 유튜브·팟캐스트 듣기 30분**을 권합니다.

## 🚀 처음 시작하기 (5분)

1. **이름**과 **Claude API 키**를 입력합니다. 한 번 입력하면 다시 묻지 않아요.
2. **음성 인식 모델**(다국어 Whisper small, 466MB)을 받습니다. 내 일본어 발음을 알아듣는 데 쓰고, 번역기의 한국어 인식에도 같은 모델을 씁니다. 영어판 앱에서 이미 받았다면 다시 받지 않아요.
3. **자연스러운 AI 음성(VOICEVOX Nemo)** 을 받습니다(약 100MB, 첫 실행 때 자동으로 시작). 사람처럼 매끄러운 신경망 일본어 음성으로, 받은 뒤에는 인터넷 없이 씁니다. 받기 전이나 지원하지 않는 컴퓨터에서는 운영체제의 일본어 음성으로 읽어 줍니다.
4. **마이크·스피커 점검**: 3초 말하고 다시 들어 보세요.
5. **레벨 테스트**를 보면 내 수준에 맞는 6개월(182일) 과정이 시작됩니다. 일본어가 처음이면 "테스트 없이 처음부터(N5) 시작"을 누르세요.

## ✨ 주요 기능

### 🎤 따라 말하기 채점 — 한자/가나 상관없이 발음으로
마이크 버튼을 누르고 말하면, 오프라인 음성 인식(Whisper)이 알아듣고 **단어마다 맞았는지** 색으로 보여 줍니다. 음성 인식은 같은 말을 「今日」로도 「きょう」로도 쓰기 때문에, 앱은 목표 문장과 들린 말을 모두 **발음 가나**(형태소 분석기 lindera + IPADIC)로 바꿔 한 박자씩 비교합니다. 숫자(7時 / 七時), 조사 は(わ)로 읽기, 장음(コーヒー / こおひい)도 같은 소리로 봅니다. 말하기 속도는 **분당 글자 수(자/분)** 로 알려 줍니다(원어민 대화 약 350자/분).

> ℹ 점수는 음성 인식이 내 말을 얼마나 잘 알아들었는지, 즉 **알아듣기 쉬운 정도(명료도)** 입니다. 원어민처럼 들리는지를 재는 점수는 아니에요. 장음·촉음(っ)·발음(ん)·청탁음(か/が)이 틀리면 다른 단어로 들려서 점수가 내려갑니다.

### ふりがな 후리가나
화면의 일본어에는 한자 위에 **읽는 법(후리가나)** 이 붙습니다. 형태소 분석으로 단어마다 읽기를 찾고, 오쿠리가나는 빼고 한자에만 답니다(食[た]べる). 익숙해지면 **설정 › 학습 › "한자 위에 후리가나 표시"** 를 끄세요.

### 📖 직독직해 — 일본어와 한국어는 어순이 같아요
일본어 문장을 **문절**(단어 + 뒤에 붙는 조사·어미)로 끊고, 조각마다 한국어 뜻을 아래에 보여 줍니다. 위아래를 이어 읽으면 그대로 한국어 문장이 됩니다.

```
昨日、 / 友達と / 映画を / 見に / 行きました。
어제    친구와    영화를    보러    갔습니다.
```

조각마다 **문장 성분 색상**이 붙습니다(🟥 주어 · 🟦 서술어 · 🟪 목적어 · 🟩 보어 · 🩷 대명사 · 🟧 지시어·수 · 회색 계열 수식어·접속어). Claude가 없을 때는 앱이 직접 문절을 나누고 내장 단어장으로 뜻을 붙입니다.

직독직해는 초반에 효과적이지만, 계속 쓰면 머릿속 번역 습관이 굳어 말이 느려집니다. 그래서 **1~2개월**은 늘 켜고, **3~4개월**은 필요할 때만, **5~6개월**은 일본어만 봅니다.

### 📘 리딩 라이브러리 — 옛날이야기부터 소설까지
- **쉬운 옛날이야기 10편(내장)**: 桃太郎, うさぎとかめ, 北風と太陽, おむすびころりん, 大きなかぶ, 浦島太郎, かさじぞう, つるの恩返し, 金のおの銀のおの, 三びきの子ぶた — 학습용으로 쉽게 다시 쓴 이야기
- **青空文庫(아오조라 문고) 원문 121권**: N4 楠山正雄의 옛날이야기·그림 동화 → N3 新美南吉·小川未明·宮沢賢治 → N2 太宰治·芥川龍之介·江戸川乱歩 → N1 夏目漱石·森鴎外 등. 저작권이 끝난 작품(新字新仮名)이라 무료로 한 번만 받아 둡니다.

문장을 누르면 **듣기 · 직독직해 · 소리 내어 읽기(채점) · 단어 뜻 · 복습 저장**을 할 수 있고, 어려우면 **✨ 쉬운 일본어로 다시 쓰기**로 내 수준에 맞게 바꿔 읽을 수 있어요.

### 📖 내장 일본어 사전 (약 6,000단어)
JLPT N5~N1 단어마다 **읽기 · 품사 · 한국어 뜻 · 예문 · 예문 해석**이 들어 있습니다(`assets/ja/words.json`). 문장 아래 단어를 누르면 인터넷이나 Claude 없이 바로 뜻이 나오고, 「行きました」→「行く」처럼 활용형도 기본형으로 찾아 줍니다.

### 🔊 자연스러운 AI 일본어 음성 — VOICEVOX Nemo
오프라인 신경망 음성 엔진 **VOICEVOX**의 **Nemo** 목소리(여성 6 · 남성 3, 설정 › 음성에서 선택)로 사람처럼 자연스럽게 읽어 줍니다. 일본어 사전(Open JTalk)으로 한자 읽기와 억양을 분석해서, 시험한 문장들을 음성 인식이 한 글자도 틀리지 않고 받아 적었습니다. **🐢 천천히 / 🐇 빠르게**도 자연스럽고, 한 번 들은 문장은 바로 다시 재생됩니다. 음성 엔진은 처음 읽을 때 메모리에 올리고(약 4초, 약 600MB) 5분 동안 쓰지 않으면 내려놓습니다. 음성: VOICEVOX Nemo.

(영어판의 Kokoro 음성은 일본어 한자를 읽지 못해 쓰지 않습니다. AI 음성을 끄면 운영체제 일본어 음성을 씁니다.)

### 🌐 자동 번역기 — 한국어로 말하면 일본어 3단계로
하고 싶은 말을 **한국어로 마이크에 말하거나** 입력하면, 같은 뜻을 **쉽게(です・ます) · 중간(일상 표현) · 고급(경어 등)** 세 가지 일본어로 보여 주고 읽어 줍니다.

```
🎤 "내일 회의 시간 좀 바꿀 수 있을까요?"
 쉽게  明日の会議の時間を変えてもいいですか。
 중간  明日の会議、時間ずらせますか？
 고급  明日の会議の時間を変更していただくことは可能でしょうか。
```

### 🔗 덩어리 표현 · 🕐 시제 3문장
- **덩어리 표현**: ～と思います, ～んですけど, ～かもしれない처럼 일본인이 늘 쓰는 틀을 통째로 익힙니다.
- **시제 3문장**: 새 단어마다 같은 생각을 세 가지 시제로 말합니다 — 현재 「～しようと思っています」(~할까 생각 중이에요) · 과거 「～しようと思っていました」 · 미래 「～するつもりです」.

### 💬 원어민 표현과 유행어
하루 1개, **예전부터 쓰던 표현**(お疲れさまです, しょうがない, 猫の手も借りたい …)과 **요즘 유행어**(エモい, それな, 推し, ぴえん …)를 번갈아 배웁니다.

### ✏ 쓰기
- **🎧 받아쓰기**: 배운 문장을 듣고 그대로 쓰기 (단어별 채점)
- **🔁 한→일 작문**: 한국어를 일본어로. 모범 답안과 달라도 뜻이 같으면(가나로 써도) 맞다고 인정해요
- **📝 일본어 일기**: AI가 조사·활용·경어를 교정하고 원어민 버전을 보여 줍니다. 교정된 글은 소리 내어 읽어 말하기로 이어져요

### 🔠 낱말 맞추기 (가나 Wordle)
배운 단어의 **읽기(히라가나)** 를 6번 안에 맞힙니다. 화면의 **50음도**를 누르거나 일본어 입력기로 칩니다.

### 📴 오프라인 대본 모드
Claude API를 쓸 수 없을 때(키 없음·크레딧 부족·네트워크 오류) 자기 표현과 회화가 자동으로 내장 대본으로 바뀝니다. 레벨 4단계(N5 / N4 / N3 / N2)마다 자기 표현 질문 30개와 대화 대본 15개, 자유 회화 400개 상황(8개 카테고리 × 50), 스피드 리딩 대본 52개(26주 × 2)가 들어 있습니다.

### 📼 주간 녹음 · 🎓 원어민 수업 · 📝 시험
- **주간 녹음**: 매주 같은 질문(「自己紹介と、今週したことを話してください。」)에 1분 동안 대답해 녹음하고 처음과 비교합니다.
- **원어민 화상 수업**: 3개월 차부터 주 1~2회, 30분씩 일본어 튜터와의 수업(예: italki)을 권합니다.
- **시험**: 2주마다 JLPT 문제 예시·JPT·OPIc 일본어로 실력을 확인하고 결과를 기록합니다.

### 📈 레벨과 기록
레벨은 7단계(초급 N5 → 능숙 N1)로 파일에 기록되고 4주마다 레벨 평가를 봅니다. **학습 기록**에서 날짜별로 무엇을 몇 분 했는지, 읽은 책, 쓴 글, 점수를 확인할 수 있어요.

## ❓ 자주 묻는 질문

**Claude API 키가 꼭 필요한가요?**
레슨 생성, 말하기·쓰기 피드백, AI 회화, 쉬운 일본어로 다시 쓰기에 사용합니다. 키가 없어도 내장 단어장·문장·옛날이야기·대본·받아쓰기 등은 쓸 수 있어요. 키는 [Anthropic Console](https://console.anthropic.com/)에서 만들고, 내 컴퓨터에만 저장됩니다.

**일본어 음성이 기계 같아요.**
설정 › 음성에서 **자연스러운 AI 음성(VOICEVOX Nemo)** 이 "준비 완료"인지 확인하세요. 받는 중이면 끝날 때까지 운영체제 음성으로 읽습니다.

**마이크가 안 돼요.**
설정 → **오디오 장치 · 마이크 점검**에서 "마이크 테스트"를 눌러 보세요. macOS는 시스템 설정 → 개인정보 보호 및 보안 → 마이크에서 SpeakUp 6M JP를 허용하세요.

**메모리를 얼마나 쓰나요?**
음성 인식 모델(small, 약 0.5~1GB)과 AI 음성 엔진(약 600MB)이 큽니다. 둘 다 쓸 때만 올리고, 쉬면(음성 인식 3분, AI 음성 5분) 내려놓습니다. 일본어 음성과 한국어 음성(번역기)은 한 모델을 함께 써서 메모리에 한 번만 올라갑니다. 일본어 사전(IPADIC)은 앱에 들어 있지만 쓸 때만 읽어서 약 5MB만 씁니다.

**내 학습 기록은 어디에 저장되나요?**

| OS | 위치 |
|---|---|
| macOS | `~/Library/Application Support/com.SpeakUp.SpeakUp6M-JP/` |
| Windows | `%APPDATA%\SpeakUp\SpeakUp6M-JP\data\` |

**문제가 생기면 무엇을 보내면 되나요?**
학습 기록 폴더의 `logs/speakup.log`를 보내 주세요. API 키는 기록하지 않습니다.
